# 二维码图片资源

请将以下二维码图片放置在此目录下：

## 必需图片

### service-qrcode.png
- **用途**：客服微信二维码
- **位置**：客服中心页面、养宠资料领取弹窗
- **建议尺寸**：800x800px
- **格式**：PNG（支持透明背景）
- **内容**：客服微信二维码（微信号：MeworaAI）

## 使用说明

1. 将您的客服微信二维码保存为 `service-qrcode.png`
2. 放置在当前目录下（`images/qrcode/`）
3. 重新编译小程序即可生效

## 临时占位方案

如果暂时没有二维码，可以：
1. 使用任意图片作为占位符
2. 或者修改代码中的图片路径显示文字说明
