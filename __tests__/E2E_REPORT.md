## 🔴 微信小程序 E2E 限制

微信小程序运行在封闭环境中，**无法使用 Playwright/Cypress** 进行标准 E2E 测试，原因：

| 限制 | 说明 |
|------|------|
| 渲染引擎 | 微信自有 WebView（非标准浏览器） |
| DOM 不可达 | 无法通过 WebDriver/CDP 操作 |
| 登录依赖 | 必须微信扫码或授权 |
| 云函数 | 在微信云环境中运行，无 HTTP 端点 |

---

## 🟢 替代方案

### 方案1：微信开发者工具自动化录制（推荐）

微信开发者工具支持「自动化录制」功能：
1. 打开微信开发者工具 → 调试器 → Automation
2. 录制用户操作序列
3. 回放验证

**覆盖场景**：
- 启动页 → 首页（冷启动）
- 症状选择 → 风险评估 → 结果页
- 宠物档案 → 新增 → 编辑 → 删除
- 医院搜索 → 列表 → 拨打电话
- 会员中心 → 购买 → 订单列表

### 方案2：miniprogram-automator（微信官方）

```javascript
const automator = require('miniprogram-automator');

// 启动小程序
const miniProgram = await automator.launch({
  projectPath: 'path/to/project'
});
const page = await miniProgram.currentPage();
// 操作元素
await page.callMethod('selectSymptom', 'vomit');
```

## 📋 核心用户流程 E2E 测试清单

### F1: 用户登录流程
- [ ] 首次打开 → 静默登录 → 首页渲染
- [ ] Token 过期 → 自动刷新 → 无感知
- [ ] 网络异常 → 离线数据兜底

### F2: 症状自查流程 🔥
- [ ] 选择宠物 → 选择症状 → 查看风险结果
- [ ] 高风险 → 紧急就医提示 + 一键拨打
- [ ] 中风险 → 附近医院列表
- [ ] 低风险 → 居家观察建议

### F3: 宠物管理流程
- [ ] 新增宠物（名称/类型/品种/年龄）
- [ ] 编辑宠物信息
- [ ] 删除宠物（确认弹窗）
- [ ] 疫苗/驱虫日期更新 → 健康状态变化

### F4: 医院搜索流程
- [ ] 关键词搜索 → 结果列表
- [ ] 拨打电话（wx.makePhoneCall）
- [ ] 查看医院详情
- [ ] 24小时急诊筛选

### F5: 会员/支付流程
- [ ] 会员状态查看
- [ ] 购买会员 → 订单创建
- [ ] 订单列表/详情

## 🚫 已知无法自动化项

| 场景 | 原因 |
|------|------|
| 微信支付回调 | 依赖微信服务器 |
| 扫码登录 | 需要真实微信账号 |
| 小程序分享 | 需要真实会话 |
| 腾讯地图 API | 依赖外部服务 Key |
