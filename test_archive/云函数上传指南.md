## 🎯 上传操作步骤（3分钟）

### 第1步：上传修复的3个云函数

```
微信开发者工具 → cloudfunctions目录
```

#### 1.1 上传 dbInit 云函数
1. 右键点击 `dbInit` 文件夹
2. 选择：**"上传并部署：云端安装依赖"**
3. 等待部署完成（约1-2分钟）

#### 1.2 上传 getPetList 云函数
1. 右键点击 `getPetList` 文件夹  
2. 选择：**"上传并部署：云端安装依赖"**
3. 等待部署完成（约1-2分钟）

#### 1.3 上传 savePet 云函数
1. 右键点击 `savePet` 文件夹
2. 选择：**"上传并部署：云端安装依赖"**  
3. 等待部署完成（约1-2分钟）

### 第2步：执行数据库初始化

```
云函数上传完成后 → 执行dbInit初始化数据库
```

1. 右键点击 `dbInit` 文件夹
2. 选择：**"云端测试"**
3. 点击：**"调用"** 按钮
4. 查看控制台输出，确认数据库初始化成功

**预期输出**:
```
🚀 开始完整数据库初始化...
✅ 集合 hospitals 初始化完成，添加了 5 条数据
🎉 数据库初始化完成！
```

### 第3步：验证部署成功

#### 3.1 检查云函数列表
1. 打开微信开发者工具
2. 点击顶部：**"云开发"** 按钮
3. 进入：**"云函数"** 标签
4. 确认以下云函数状态为**"正常"**：
   - ✅ dbInit
   - ✅ getPetList  
   - ✅ savePet

#### 3.2 检查数据库
1. 在云开发控制台，进入：**"数据库"** 标签
2. 检查集合状态：
   - ✅ `hospitals` - 应该有5条记录
   - ✅ `pets` - 空集合（正常）
   - ✅ `users` - 应该有用户数据
   - ✅ `symptom_records` - 空集合（正常）
