# 🔧 基础库下载失败 - ECONNRESET 解决方案

## ❌ 问题分析

**错误信息**: `下载基础库版本 3.0.2 失败： read ECONNRESET`
**问题类型**: 网络连接被重置
**影响范围**: 无法切换基础库版本

---

## 🚀 立即解决方案

### **方案一：网络重置（推荐）**

#### **步骤1: 重启微信开发者工具**
```
1. 完全关闭微信开发者工具
2. 重新打开工具
3. 尝试再次切换基础库版本
```

#### **步骤2: 检查网络连接**
```
1. 检查网络连接是否正常
2. 尝试访问其他网站确认网络可用
3. 如果使用WiFi，尝试切换到有线网络
```

#### **步骤3: 清除工具缓存**
```
1. 微信开发者工具 → 设置 → 通用
2. 点击"清除缓存"
3. 重启工具
4. 再次尝试切换基础库版本
```

---

### **方案二：使用当前基础库版本**

#### **当前情况确认**
```
项目当前配置: libVersion: "3.0.0"
工具实际使用: 可能是其他版本
```

#### **临时解决方案**
```json
// project.config.json 保持当前配置
{
  "libVersion": "3.0.0"
}
```

**在微信开发者工具中**：
```
1. 详情 → 本地设置 → 调试基础库
2. 选择一个当前可用的版本（不要强制切换）
3. 使用当前可用的版本进行开发测试
```

---

### **方案三：网络环境优化**

#### **检查防火墙设置**
```
1. 临时关闭防火墙
2. 重新尝试下载基础库
3. 如果成功，添加微信开发者工具到防火墙例外
```

#### **检查代理设置**
```
1. 微信开发者工具 → 设置 → 代理
2. 设置为"不使用代理"
3. 重新尝试下载基础库
```

#### **更换网络环境**
```
1. 如果在公司网络，尝试切换到手机热点
2. 如果在家庭网络，尝试重启路由器
3. 使用VPN切换网络节点
```

---

### **方案四：工具重置**

#### **完全重置微信开发者工具**
```
1. 完全关闭微信开发者工具
2. 删除工具的用户数据（谨慎操作）：
   Windows: %APPDATA%\微信开发者工具
   Mac: ~/Library/Application Support/微信开发者工具
3. 重新安装微信开发者工具
4. 打开项目，重新配置
```
