# 腾讯地图API配置指南

## 📋 概述

本项目已集成腾讯地图API，提供真实的地图显示、位置搜索和导航功能。要启用真实地图数据，需要配置腾讯地图API密钥。

## 🔧 配置步骤

### 1. 申请腾讯地图API密钥

#### 步骤1：注册腾讯地图账号
1. 访问 [腾讯地图开放平台](https://lbs.qq.com/)
2. 点击右上角"控制台"
3. 使用微信扫码登录

#### 步骤2：创建应用
1. 在控制台中，点击"应用管理" → "我的应用"
2. 点击"创建应用"
3. 填写应用信息：
   - **应用名称**：宠物症状自查小程序
   - **应用类型**：微信小程序
   - **应用描述**：宠物健康自查和医院导航

#### 步骤3：添加Key
1. 创建应用后，点击"添加Key"
2. 选择Key类型：**WebServiceAPI**
3. 填写Key信息：
   - **Key名称**：pet-symptom-miniprogram
   - **描述**：小程序地图服务
4. 配置域名白名单（重要！）：
   ```
   https://apis.map.qq.com
   ```

#### 步骤4：获取密钥
- 创建成功后，会显示一个以`OB4BZ-`开头的字符串
- 复制这个密钥，格式类似：`OB4BZ-xxxxxxxxxxxxxxxx-xxxxxxxx`

### 2. 配置小程序项目

#### 方法A：直接修改配置文件（推荐）

1. 打开文件：`miniprogram/utils/mapConfig.js`

2. 找到这行代码：
   ```javascript
   key: 'YOUR_TENCENT_MAP_KEY', // 请替换为你的真实API密钥
   ```

3. 将`YOUR_TENCENT_MAP_KEY`替换为你申请的真实API密钥：
   ```javascript
   key: 'OB4BZ-xxxxxxxxxxxxxxxx-xxxxxxxx', // 你的真实API密钥
   ```

4. 保存文件

#### 方法B：通过微信开发者工具配置

1. 打开微信开发者工具
2. 在项目根目录创建`config.js`文件：
   ```javascript
   module.exports = {
     tencentMapKey: '你的API密钥'
   }
   ```

3. 修改`mapConfig.js`引用配置文件

### 3. 配置小程序权限

#### 在微信小程序后台配置服务器域名

1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 进入你的小程序后台
3. 点击"开发" → "开发管理" → "开发设置"
4. 在"服务器域名"中，修改**request合法域名**：
   ```
   https://apis.map.qq.com
   ```

#### 检查项目配置

确认`project.config.json`中包含以下配置：
```json
{
  "setting": {
    "urlCheck": true  // 正式环境建议开启
  }
}
```

## 📊 API使用说明

### 主要API调用：

```javascript
// 搜索附近医院
mapService.searchNearbyHospitals(latitude, longitude, radius)

// 打开导航
mapService.openNavigation(hospital)

// 拨打电话
mapService.makePhoneCall(phoneNumber)
```

### API限制：

- **免费额度**：每Key每日100万次调用
- **并发限制**：每秒5次
- **搜索范围**：半径最大50公里

## 🔍 故障排查

### 问题1：地图不显示
**原因**：API密钥未配置或配置错误
**解决**：
1. 检查`mapConfig.js`中的密钥是否正确
2. 确认密钥类型为WebServiceAPI
3. 检查微信小程序后台是否配置了合法域名

### 问题2：搜索无结果
**原因**：位置权限未获取或API调用失败
**解决**：
1. 检查小程序位置权限是否开启
2. 查看控制台错误日志
3. 确认API密钥额度是否充足

### 问题3：导航失败
**原因**：医院坐标数据不完整
**解决**：
1. 检查医院数据是否包含`latitude`和`longitude`
2. 确认坐标格式正确（GCJ-02坐标系）
