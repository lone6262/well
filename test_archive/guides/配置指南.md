# 云开发环境ID配置指南

## 🔍 如何获取正确的环境ID

### **方法1：查看云开发控制台**

1. **打开云开发控制台**
   - 在微信开发者工具中点击"云开发"按钮
   - 进入云开发管理界面

2. **查看环境ID**
   - 在云开发控制台顶部，找到"环境ID"
   - 格式通常为：`cloud1-xxxxx` 或自定义名称
   - **复制这个环境ID**

3. **更新到小程序配置**
   - 将环境ID填入 `miniprogram/app.js` 中的 `env` 字段
   - 两个地方都要更新（第6行和第15行）

### **方法2：检查project.config.json**

1. **查看项目配置文件**
   - 在根目录找到 `project.config.json`
   - 查看 `appid` 字段是否正确：`wxee33a0c47421db2c`

2. **确认云开发环境已开通**
   - 在微信开发者工具中点击"云开发"
   - 如果提示"开通云开发"，按提示开通
   - 开通后会自动创建一个默认环境

## ⚠️ 重要提示

- **环境ID必须真实存在**，否则云函数调用会失败
- **同一个AppID可以创建多个云开发环境**
- **不同环境之间数据是隔离的**

## 🚀 快速配置步骤

1. 复制正确的环境ID
2. 更新 `miniprogram/app.js` 中的环境ID配置
3. 保存文件并重新编译
4. 重新启用登录逻辑（取消注释）
