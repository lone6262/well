# 🧪 云开发功能测试指南

## 🎯 测试目标

验证云开发功能已正确启用，且不影响启动性能。

---

## ✅ 测试清单

### **1. 启动性能测试**
```
测试步骤：
1. 微信开发者工具 → 清除缓存 → 全部清除
2. 点击"编译"按钮
3. 观察控制台日志

预期结果：
✅ Launch Time: < 2000 ms
✅ 控制台显示："小程序启动完成" 立即输出
✅ 几秒后显示："云开发环境初始化完成"（异步）
✅ 无 timeout 错误
```

### **2. 云开发状态测试**
```
测试步骤：
在控制台执行：
const app = getApp()
console.log('云开发状态:', app.globalData.cloudInitialized)

预期结果：
✅ 几秒后显示: true（云开发初始化成功）
```

### **3. 云数据库连接测试**
```
测试步骤：
在控制台执行：
wx.cloud.database().collection('test').get({
  success: res => console.log('数据库连接成功:', res),
  fail: err => console.error('数据库连接失败:', err)
})

预期结果：
✅ 成功连接数据库（如果云环境已开通）
✅ 或显示环境未配置错误（正常，需要先开通云环境）
```

### **4. 云函数调用测试**
```
测试步骤：
1. 在云开发控制台创建云环境
2. 上传云函数
3. 在小程序中调用云函数

预期结果：
✅ 云函数调用成功
✅ 返回结果正确
```

## 🚨 故障排查

### **问题1: 云开发初始化超时**
```
解决方案：已内置超时保护机制
- 5秒超时自动降级到本地功能
- 不影响小程序正常使用
```

### **问题2: 云环境未配置**
```
解决方案：
1. 在微信开发者工具中点击"云开发"
2. 按提示开通云环境
3. 获取环境ID并更新到app.js中
```

### **问题3: 云函数调用失败**
```
解决方案：
1. 检查云函数是否已上传部署
2. 检查云函数权限配置
3. 查看云函数日志排查问题
```
