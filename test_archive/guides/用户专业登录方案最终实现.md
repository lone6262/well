addPet: function() {
  var app = getApp();

  // 检查是否游客模式
  if (app.globalData.isGuest) {
    // 引导用户授权
    app.requestUserAuthorization(function(result) {
      if (result.success) {
        // 授权成功，继续添加宠物
        this.showAddPetForm();
      } else {
        // 用户拒绝，继续游客模式添加
        this.showAddPetForm();
      }
    });
  } else {
    // 已授权，直接添加宠物
    this.showAddPetForm();
  }
}

## 📊 完整的登录流程

### **启动阶段（静默登录）**
```
小程序启动
    ↓
wx.login() 获取code ← 用户无感知
    ↓
调用silentLogin云函数
    ↓
换取openid，生成token
    ↓
前端存储token
    ↓
进入小程序（游客模式："宠物主人"）
```

### **授权阶段（按需触发）**
```
用户点击"添加宠物"
    ↓
检测到游客模式
    ↓
引导授权：wx.getUserProfile()
    ↓
用户同意授权
    ↓
调用saveUserProfile云函数
    ↓
保存头像昵称到数据库
    ↓
更新为正式用户
```

### **Token续期**
```
每次请求时检测
    ↓
如果token过期（7天）
    ↓
自动重新静默登录
    ↓
获取新token
    ↓
继续使用
```
