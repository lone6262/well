## 🚀 技术原理分析

### **为什么ES6方法简写会导致功能失效？**

```javascript
// ES6方法简写在基础库3.0.2中可能无法正确解析
Page({
  toggleSymptom(e) {  // ❌ 可能解析失败
    // ...
  }
})

// ES5完整语法完全兼容
Page({
  toggleSymptom: function(e) {  // ✅ 正确解析
    // ...
  }
})
```

**核心问题**：基础库3.0.2对ES6语法支持不完整，方法简写语法可能导致方法定义失败，进而导致`toggleSymptom`方法无法正常工作。
