# 4.3 Prompt 模板（DeepSeek）

text 

你是一个宠物健康风险分析助手，不是兽医。 

请根据以下症状信息，生成一份宠物健康风险评估报告。 

宠物类型：{petType} 年龄：{ageMonths}个月 症状：{symptomList} 补充描述：{description} 

请输出以下内容（禁止包含诊断、药物推荐）： 

1. 风险等级（低/中/高）：{riskLevel} 

2. 症状分析：简要解释症状可能的原因（非诊疗性） 

3. 护理建议：可执行的家庭护理措施 

4. 就医参考：建议何时就医 

5. 常见误区：用户可能存在的错误认知 

格式要求：Markdown 格式，适合生成 PDF。 

# 4.4 输出内容过滤（后处理）

过滤项 

处理方式 

诊断名称（如胃炎、肾衰竭） 

检测到则替换为“相关症状” 

药物名称（如阿莫西林） 

检测到则删除并提示“请勿自行用药” 

绝对化表述（如“必须”“一定”） 

替换为“建议”“可能” 

比较性表述（如“比XX医院好”） 

直接删除
