# 规则引擎逻辑详细开发文档 

# ## 1. 规则引擎概述

# ### 1.1 定位

规则引擎是 V1.0 种子版的核心决策模块，**不调用任何 AI 模型**，仅基于预定义的规则对 用户提交的症状进行风险分级。 

# ### 1.2 目标

- 快速判断风险等级（低/中/高） 

- 高风险直接触发急救通道，防止用户延误就医 

- 为后续 V1.5 的 AI 报告提供基础风险分级 

# ### 1.3 输入输出

```markdown
| 类型 | 内容 |
| ---- | ---- |
| **输入** | 症状 ID 列表（`symptomIds`）、宠物类型（`petType`）、补充描述（`description`） |
| **输出** | 风险等级（`low` / `mid` / `high`）、固定建议文本、记录 ID |
| **存储** | 写入 `symptom_records` 表 |
--- 
```

# ## 2. 核心逻辑流程

接收请求 

↓ 

校验入参（症状列表不为空） 

↓ 

第一步：高风险熔断检查 

↓ 

若命中 → 直接返回 high 

↓ 

第二步：中风险条件检查 

↓ 

若命中 → 返回 mid 

↓ 

第三步：默认低风险 

↓ 

返回 low 

↓ 

存储记录并返回结果

## 3. 详细规则定义 

### 3.1 高风险熔断规则（优先级最高） 

#### 触发条件 

`symptomIds` 中包含以下任一 **高危症状 ID**： 

| 症状 ID | 对应症状 | 说明 | 

| `seizure` | 抽搐 | 神经系统严重异常 | 

| `coma` | 昏迷 | 意识丧失 | 

| `dyspnea` | 呼吸困难 | 呼吸系统严重异常 | 

| `bleeding` | 持续出血 | 外伤或内出血 | 

| `hematuria` | 尿血 | 泌尿系统严重异常 | 

| `paralysis` | 瘫痪 | 运动功能丧失 | 

| `collapse` | 虚脱 | 突然倒下 | 

| `cyanosis` | 发绀 | 黏膜发紫（缺氧） | 

#### 输出 

```json 

{ 

```json
"riskLevel": "high",
"advice": "高风险，建议立即就医！请勿拖延，尽快前往最近的宠物医院。",
"action": "emergency" // 前端据此跳转急救通道
} 
```

# 特殊处理

 一旦命中高风险，不再进行中/低风险判断 

 即使同时包含低风险症状，也按高风险处理 

# 3.2 中风险规则（未被高风险拦截时）

# 触发条件（满足任一即可）

```txt
规则编号 条件 说明
R1 症状数量 ≥3，且包含 vomit（呕吐）或 diarrhea（腹泻）或 fever （发热）
R2 症状数量 ≥3，且补充描述中包含关键词：反复、持续、加重、多次、不
提示症状严
断
R3 症状数量 ≥4（不考虑具体症状）
多系统症状情
R4 包含 lethargy（精神萎靡）+ 任意 2 个其他症状 精神差 + 多 
```

async function saveAndReturn(riskLevel, advice, action) {
    const record = {
    openid,
    petId,
    symptoms: symptomIds,
    description,
    riskLevel,
    status: 'completed',
    createdAt: db.serverDate()
    }

    const res = await db.collection('symptom_records').add({ data: record })
    return {
    code: 0,
    data: {
    recordId: res._id,
    riskLevel,
    advice,
    action,
    symptomSummary: symptomIds.join('、')
    }
    }
}

# 7. 异常处理与边界情况

```txt
场景    处理方式
症状列表为空    返回 code: 400，前端提示“请至少选择一个症状”
宠物不存在    返回 code: 404，前端提示“宠物不存在，请重新选择” 
```

场景 处理方式 

数据库写入失败 返回 code: 500，前端提示“系统繁忙，请重试” 

云函数超时（>3 秒） 前端显示“评估超时”，建议用户重试 

高并发 云函数自动扩容，无特殊处理
