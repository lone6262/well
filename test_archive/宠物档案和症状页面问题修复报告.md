# 宠物档案和症状页面问题修复报告

## 🚨 发现的问题

根据错误日志 `127.0.0.1-1779760676459.log`，发现**2个严重功能问题**：

### 问题1：宠物类型选不了 ❌
**错误信息**：
```
Component "pages/pet/profile" does not have a method "selectType" to handle event "tap".
```

**影响**：用户无法选择宠物类型（猫/狗），导致无法添加宠物

### 问题2：选择宠物后点下一步没反应 ❌  
**错误信息**：
```
Component "pages/symptom/guide" does not have a method "nextStep" to handle event "tap".
```

**影响**：症状自查功能完全无法使用，无法进入下一步骤

---

## 🔍 根本原因分析

### 问题1根因
**wxml中有调用，但js中缺少方法实现**：

在 `pages/pet/profile.wxml` 第66-67行：
```xml
<view class="type-option {{formData.type === 'cat' ? 'active' : ''}}" bindtap="selectType" data-type="cat">🐱 猫</view>
<view class="type-option {{formData.type === 'dog' ? 'active' : ''}}" bindtap="selectType" data-type="dog">🐶 狗</view>
```

但在 `pages/pet/profile.js` 中**缺少 `selectType` 方法**

### 问题2根因
**wxml中有调用，但js中缺少方法实现**：

在 `pages/symptom/guide.wxml` 第81行：
```xml
<button class="primary-btn" bindtap="nextStep">
  {{currentStep === 3 ? '提交评估' : '下一步'}}
</button>
```

但在 `pages/symptom/guide.js` 中**缺少 `nextStep` 和 `prevStep` 方法**

---

## ✅ 修复方案

### 修复1：添加宠物类型选择功能

**在 `pages/pet/profile.js` 中添加 `selectType` 方法**：

```javascript
// 选择宠物类型
selectType: function(e) {
  var type = e.currentTarget.dataset.type
  this.setData({
    'formData.type': type
  })
},
```

**功能说明**：
- 🐱 点击"猫"选项 → 将type设置为'cat'
- 🐶 点击"狗"选项 → 将type设置为'dog'  
- ✅ 视觉反馈：选中的类型会高亮显示

### 修复2：添加症状向导步骤控制

**在 `pages/symptom/guide.js` 中添加步骤控制方法**：

```javascript
// 下一步 / 提交评估
nextStep: function() {
  var self = this

  // 如果是第3步，提交评估
  if (self.data.currentStep === 3) {
    self.submitAssessment()
    return
  }

  // 验证当前步骤
  if (self.data.currentStep === 1) {
    // 步骤1：验证是否选择了宠物
    if (!self.data.selectedPet) {
      wx.showToast({
        title: '请选择宠物',
        icon: 'none'
      })
      return
    }

    // 进入步骤2
    self.setData({
      currentStep: 2
    })

  } else if (self.data.currentStep === 2) {
    // 步骤2：验证是否选择了症状
    if (self.data.selectedSymptoms.length === 0) {
      wx.showToast({
        title: '请至少选择一个症状',
        icon: 'none'
      })
      return
    }

    // 进入步骤3
    self.setData({
      currentStep: 3
    })
  }
},

// 上一步
prevStep: function() {
  var self = this

  if (self.data.currentStep > 1) {
    self.setData({
      currentStep: self.data.currentStep - 1
    })
  }
},
```

**功能说明**：
- **步骤1→2**: 验证宠物选择后进入症状选择
- **步骤2→3**: 验证症状选择后进入描述填写  
- **步骤3**: 提交症状评估
- **返回**: 可以返回上一步骤
