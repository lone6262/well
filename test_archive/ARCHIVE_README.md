# Test Archive 目录

本目录用于存放well项目中与核心业务无关的测试文件、报告、脚本和备份文件。

## 目录结构

- `reports/` - 各种修复报告、测试报告、完成报告等
- `guides/` - 配置指南、测试指南、使用说明等文档
- `scripts/` - 测试脚本、诊断工具、验证工具等
- `backups/` - 备份文件、配置文件等
- `cloudfunctions_backup/` - 云函数备份目录

## 使用说明

1. 所有测试相关的文件请放在此目录下对应的分类文件夹中
2. 新增测试文件时，请根据文件类型选择合适的子目录
3. 建议定期清理过期或不再需要的测试文件
4. 项目核心业务文件应保持在主目录中

## 文件分类说明

### reports/
存放各种报告类文件，包括：
- 修复报告
- 测试报告  
- 完成报告
- 诊断报告

### guides/
存放指南类文件，包括：
- 配置指南
- 测试指南
- 使用说明
- 验证清单

### scripts/
存放脚本类文件，包括：
- 测试脚本
- 诊断工具
- 验证工具
- 相关页面文件(.js, .wxml, .wxss等)

### backups/
存放备份类文件，包括：
- 配置备份
- 文件备份
- 临时保存的配置文件
