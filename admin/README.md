# 后台管理系统

> 宠物健康自查小程序的配套 Web 管理后台，基于微信云开发构建。

---

## 项目简介

本管理后台为管理员提供 Web 界面，用于管理小程序用户、订单、知识内容，查看运营数据统计，并在线修改系统配置。无需额外服务器，全部运行在微信云开发基础设施上。

### 核心功能

| 模块 | 功能 |
|------|------|
| 📊 数据统计 | 用户/订单/收入/会员多维度统计，支持今日/近7天/近30天/自定义时间范围 |
| 👤 用户管理 | 用户列表查询、搜索过滤、会员状态筛选、用户统计信息展示 |
| 📦 订单管理 | 订单列表查询、按状态/类型/时间过滤、退款操作 |
| 📝 内容管理 | 知识文章的新建/编辑/发布/归档/删除，按分类和状态过滤 |
| ⚙️ 系统设置 | 价格配置、会员额度在线修改，实时生效 |

### 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | HTML5 + CSS3 + Vanilla JavaScript（无框架） |
| 后端 | 微信云开发（云函数 + 云数据库） |
| 认证 | JWT Token（HMAC-SHA256）+ ADMIN_SECRET |
| 部署 | 云开发静态网站托管 |

### 浏览器兼容性

| Chrome 80+ | Edge 80+ | Firefox 75+ | Safari 13+ |

## 部署前置要求

在开始部署前，请确认以下条件已满足：

- [ ] 已安装**微信开发者工具**（最新稳定版）
- [ ] 拥有微信小程序账号，且**已开通云开发**
- [ ] 云开发环境**已创建**并获取了**环境 ID**
- [ ] 小程序项目已关联云开发环境
- [ ] `system_config` 集合中已配置 `admin_secret`（通过 `dbInit` 云函数初始化）
- [ ] 浏览器支持 ES6+（Chrome 80+ 推荐）

## 部署步骤

### 1. 部署云函数

在微信开发者工具中，依次部署以下云函数：

1. **认证相关**
   - `cloudfunctions/adminLogin`

2. **用户管理**
   - `cloudfunctions/adminGetUsers`

3. **订单管理**
   - `cloudfunctions/adminGetOrders`
   - `cloudfunctions/adminUpdateOrder`

4. **内容管理**
   - `cloudfunctions/adminGetArticles`
   - `cloudfunctions/adminSaveArticle`
   - `cloudfunctions/adminDeleteArticle`

5. **数据统计**
   - `cloudfunctions/adminGetStats`

6. **系统配置**
   - `cloudfunctions/adminGetConfig`
   - `cloudfunctions/adminUpdateConfig`

> **关于共享模块**：每个云函数目录内已包含独立的 `common/` 子目录（`constants.js` + `admin-auth.js`），部署时会自动打包上传，无需额外操作。

**操作步骤**：
1. 打开微信开发者工具
2. 右键每个云函数文件夹 → 上传并部署：云端安装依赖
3. 等待部署完成

### 2. 配置云开发静态网站托管

#### 2.1 开启静态网站托管

1. 打开微信云开发控制台
2. 进入您的环境
3. 点击左侧「静态网站托管」
4. 点击「开启」按钮

#### 2.2 上传管理后台文件

1. 在静态网站托管页面，点击「文件管理」
2. 创建以下目录结构：
   ```
   /
   ├── css/
   │   └── style.css
   ├── js/
   │   ├── app.js
   │   ├── articles.js
   │   ├── auth.js
   │   ├── config.js
   │   ├── orders.js
   │   ├── stats.js
   │   └── users.js
   ├── index.html
   └── dashboard.html
   ```

3. 上传所有文件（可以拖拽上传）

### 3. 配置云函数环境ID

编辑 `admin/js/config.js` 文件：

```javascript
const TCB_CONFIG = {
  env: 'your-env-id'  // 替换为您的云开发环境ID
};
```

同样编辑 `admin/index.html`：

```javascript
const TCB_CONFIG = {
  env: 'your-env-id'  // 替换为您的云开发环境ID
};
```

**获取环境ID**：
1. 打开微信开发者工具
2. 点击「云开发」
3. 在「设置」中找到「环境ID」

### 4. 配置安全规则（可选）

在静态网站托管中配置访问规则：

1. 进入「设置」→「安全规则」
2. 添加访问白名单（如果需要限制访问IP）
3. 配置自定义域名（可选）

## 使用说明

### 登录管理后台

1. 访问静态网站托管提供的域名（或自定义域名）
2. 输入管理员密钥（ADMIN_SECRET）
3. 登录成功后进入管理界面

**获取管理员密钥**：
- 在数据库 `system_config` 集合中查找 `admin_secret` 字段
- 或通过 `dbInit` 云函数设置

### 功能模块

#### 数据统计
- 查看用户、订单、收入、会员等核心指标
- 支持按今日、近7天、近30天查看趋势

#### 用户管理
- 查看用户列表
- 搜索用户（昵称、ID）
- 按会员状态过滤
- 查看用户统计数据

#### 订单管理
- 查看订单列表
- 按状态、类型过滤
- 查看订单详情
- 退款操作

#### 内容管理
- 新建/编辑知识文章（一篇云函数同时处理新建和编辑）
- 发布/下架文章
- 归档/删除文章
- 按分类、状态过滤

#### 系统设置
- 调整价格配置
- 修改会员额度
- 实时生效

## 注意事项

1. **安全建议**
   - 定期更换管理员密钥
   - 使用强密码
   - 限制访问IP

2. **权限控制**
   - 管理后台使用独立的 ADMIN_SECRET 验证
   - Token 有效期24小时
   - 自动登出机制

3. **数据保护**
   - 敏感操作需二次确认
   - 建议记录管理操作日志

4. **配额限制**
   - 微信云开发免费额度详见 [开发文档 - 云开发资源配额](开发文档.md#云开发资源配额)
   - 管理后台日常使用量较低，免费额度通常足够

## 常见问题

### 1. 登录后提示 "Token无效或已过期"

**原因**：Token已过期（24小时有效期）

**解决**：重新登录

### 2. 云函数调用失败

**原因**：环境ID配置错误或云函数未部署

**解决**：
1. 检查 `config.js` 中的环境ID
2. 确认所有云函数已部署

### 3. 无法加载数据

**原因**：权限不足或网络问题

**解决**：
1. 检查管理员密钥是否正确
2. 查看浏览器控制台错误信息
3. 确认云数据库权限配置

### 4. 如何修改管理员密钥？

在云开发控制台 → 数据库 → `system_config` 集合中修改 `admin_secret` 字段。

### 5. 部署后页面空白？

**原因**：静态网站托管文件未正确上传或路径不匹配

**解决**：
1. 确认所有文件已上传到正确路径
2. 检查浏览器控制台的 404 错误
3. 确认 `index.html` 和 `dashboard.html` 在根目录
