## 系统概述

### 项目简介

管理后台系统是宠物健康自查小程序的配套管理系统，基于微信云开发构建，无需额外服务器。管理员可以通过Web界面管理用户、订单、内容，查看数据统计，并在线修改系统配置。

### 核心特性

- **用户管理**：查看用户列表、搜索过滤、会员状态管理
- **订单管理**：订单列表查询、状态管理、退款操作
- **内容管理**：知识文章的创建、编辑、发布、归档
- **数据统计**：用户、订单、收入等多维度统计展示
- **系统设置**：价格配置、会员额度在线修改

### 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | HTML5, CSS3, Vanilla JavaScript |
| 后端 | 微信云开发（云函数 + 云数据库）|
| 认证 | JWT Token + ADMIN_SECRET |
| 部署 | 云开发静态网站托管 |

## 功能模块

### 1. 认证模块

**功能**：管理员身份验证

**流程**：
1. 管理员在登录页面输入 `ADMIN_SECRET`
2. 前端调用 `adminLogin` 云函数验证密钥
3. 验证成功后生成 Admin Token（24小时有效）
4. Token 存储在 `localStorage`
5. 后续请求携带 Token 进行身份验证

**安全机制**：
- Token 签名验证（HMAC-SHA256）
- Token 自动过期机制
- 前端自动跳转认证

### 2. 用户管理

**功能**：查看和管理小程序用户

**特性**：
- 分页查询用户列表
- 按昵称或 openid 搜索
- 按会员状态过滤（全部/会员/非会员）
- 显示用户统计信息（宠物数、订单数、报告数）

**权限**：需要管理员 Token

### 3. 订单管理

**功能**：查看和管理订单

**特性**：
- 分页查询订单列表
- 按订单状态过滤（待支付/已支付/已退款等）
- 按订单类型过滤（报告订单/会员订单）
- 按时间范围查询
- 订单退款操作
- 关联用户信息展示

**权限**：需要管理员 Token

### 4. 内容管理

**功能**：管理知识库文章

**特性**：
- 分页查询文章列表
- 按分类过滤（消化系统/呼吸系统等）
- 按状态过滤（已发布/草稿/已归档）
- 新建/编辑文章
- 发布/下架文章
- 归档/删除文章（支持硬删除）

**权限**：需要管理员 Token

### 5. 数据统计

**功能**：查看运营数据统计

**统计维度**：
- 用户统计：总数、今日新增、增长率
- 订单统计：总数、已支付、转化率
- 收入统计：总收入、今日收入、客单价
- 会员统计：总数、有效会员、活跃率
- 记录统计：自查总数、报告生成数

**时间范围**：
- 总览（今日 + 总计）
- 今日统计
- 近7天统计
- 近30天统计
- 自定义时间范围

**权限**：需要管理员 Token

### 6. 系统设置

**功能**：在线修改系统配置

**可配置项**：
- 价格配置（首份报告、标准报告、月卡、年卡）
- 会员额度（月卡每月额度、年卡每月额度）

**实时生效**：修改后立即生效，无需重启

**权限**：需要管理员 Token

### 共享模块

#### admin-auth.js — 管理员认证模块

**[cloudfunctions/common/admin-auth.js](../cloudfunctions/common/admin-auth.js)** 是所有管理端云函数的共享认证中间件。

> **部署策略**：微信云开发每个云函数独立部署，不会自动包含外部目录。因此每个 admin 云函数目录内都有独立的 `common/` 子目录副本。`cloudfunctions/common/` 是开发时的源模板，修改共享模块后需同步到各云函数的 `common/` 子目录。

**依赖关系**：
- 依赖 `common/constants.js` 中的 `SERVER_CONFIG`（获取 `ADMIN_SECRET`）和 `warmupConfig`（从数据库加载密钥）
- 使用 Node.js 内置 `crypto` 模块进行 HMAC-SHA256 签名

**导出函数**：

```javascript
const { verifyAdminToken, generateAdminToken, validateAdminRequest }
  = require('../common/admin-auth');
```

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `generateAdminToken()` | 无 | `string` | 生成 Base64 编码的管理员 Token，格式：`payload.signature` |
| `verifyAdminToken(token)` | `token: string` | `boolean` | 验证 Token 签名、类型和有效期 |
| `validateAdminRequest(event)` | `event: object` | `{ valid, error }` | 综合验证，包含 Token 存在性检查和有效性验证 |

**Token 结构**：

Token 分为两部分，用 `.` 分隔：
1. **Payload**（Base64）：`{ type: "admin", timestamp: 1717760000000, expiresIn: 86400000 }`
2. **Signature**（Hex）：`HMAC-SHA256(payloadStr, ADMIN_SECRET)`

**有效期**：24 小时（`24 * 60 * 60 * 1000` 毫秒）

**云函数使用示例**：

```javascript
const { validateAdminRequest } = require('../common/admin-auth');
const { warmupConfig } = require('../common/constants');

exports.main = async (event, context) => {
  await warmupConfig(db);  // 必须先加载密钥到 SERVER_CONFIG

  const auth = validateAdminRequest(event);
  if (!auth.valid) {
    return { code: 401, msg: auth.error, data: {} };
  }

  // 业务逻辑...
};
```

> **注意**：`adminLogin` 云函数内置了自己的 Token 生成逻辑，不依赖此共享模块。其他管理端云函数统一使用此模块验证 Token。

## 接口文档

### 统一错误码

所有管理端 API 返回统一的 `{ code, msg, data }` 结构。`code` 取值如下：

| 错误码 | 常量名 | 含义 | 触发条件 |
|--------|--------|------|----------|
| `0` | `SUCCESS` | 成功 | 请求正常处理 |
| `-1` | `ERROR` | 业务错误 | 参数校验失败、操作不合法等 |
| `401` | `UNAUTHORIZED` | 未授权 | Token 缺失、无效或已过期 |
| `404` | `NOT_FOUND` | 未找到 | 请求的资源不存在 |
| `500` | `SERVER_ERROR` | 服务器错误 | 数据库异常、云函数执行异常等 |

**错误码定义位置**：[cloudfunctions/common/constants.js](../cloudfunctions/common/constants.js) 中的 `RESPONSE_CODE` 常量。

**前端处理建议**：
- `0`：正常处理 `data` 中的数据
- `401`：清除本地 Token，跳转登录页
- `-1` / `500`：显示 `msg` 中的错误提示，提供重试按钮
- `404`：显示"资源不存在"提示

### 命名约定说明

**前端与数据库字段命名不一致说明**：

前端 API 请求/响应使用**驼峰命名**（camelCase），但云数据库存储使用**下划线命名**（snake_case）。云函数负责在两者之间进行转换：

| 层面 | 命名风格 | 示例 |
|------|----------|------|
| 前端 JS / API 参数 | 驼峰 camelCase | `targetPet`, `coverImage`, `sortOrder` |
| 云数据库文档字段 | 下划线 snake_case | `target_pet`, `cover_image`, `sort_order` |
| 云函数返回数据 | 驼峰 camelCase | 云函数读取 DB 后转换后返回 |

> **注意**：编写前端代码时应使用驼峰命名，云函数内部访问数据库时使用下划线命名。

## 安全说明

### 认证机制

**管理员 Token**：
- 使用 HMAC-SHA256 签名
- Payload 包含类型、时间戳、有效期
- 有效期 24 小时

**验证流程**：
1. 前端携带 Token 请求云函数
2. 云函数验证 Token 签名
3. 检查 Token 类型和有效期
4. 验证通过后执行业务逻辑

### 安全建议

1. **密钥保护**
   - ADMIN_SECRET 仅存储在数据库中
   - 不将密钥写入代码
   - 定期更换管理员密钥

2. **访问控制**
   - 使用静态网站托管的白名单功能
   - 配置 IP 访问限制（如需要）
   - 启用 HTTPS（自动支持）

3. **操作审计**
   - 记录管理操作日志（待实现）
   - 敏感操作二次确认
   - 监控异常访问行为

4. **数据保护**
   - 使用云数据库的权限规则
   - 敏感数据加密存储
   - 定期备份数据库

### 权限说明

**云函数权限**：
- 所有管理端云函数都需要验证 adminToken
- adminToken 通过 ADMIN_SECRET 生成
- 丢失 Token 后需重新登录

**数据库访问**：
- 读取操作：允许
- 写入操作：允许
- 删除操作：允许（需二次确认）

### 常见问题

**Q: 登录后提示 "Token无效或已过期"？**

A: Token 有效期为 24 小时，过期后需要重新登录。

**Q: 云函数调用失败？**

A: 检查以下事项：
- 环境ID是否正确配置
- 云函数是否已部署
- 管理员密钥是否正确

A: 检查浏览器控制台错误信息，确认：
- Token 是否有效
- 云数据库权限是否正确
- 网络连接是否正常

**Q: 如何修改管理员密钥？**

A: 在云开发控制台 → 数据库 → system_config 集合中修改 `admin_secret` 字段。
