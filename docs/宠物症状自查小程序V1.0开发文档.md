## 🎯 项目简介

### 项目定位
宠物症状自查小程序是一款基于微信小程序平台的智能健康管理工具，为宠物主人提供症状自查、健康档案管理、附近医院导航等核心功能，帮助用户快速评估宠物健康状况，及时获得专业医疗帮助。

### 核心价值
- **快速评估**：AI驱动的症状自查系统，3分钟内完成健康评估
- **健康管理**：完整的宠物健康档案，记录疫苗、驱虫等关键信息
- **紧急救助**：24小时宠物医院快速定位和导航
- **用户友好**：现代化UI设计，操作简单直观

### 技术栈选型
- **前端**：微信小程序原生框架 (WXML + WXSS + JavaScript)
- **后端**：微信云开发 (云函数 + 云数据库 + 云存储)
- **地图服务**：腾讯地图API
- **开发工具**：微信开发者工具

// 风险评分计算
function calculateRiskScore(symptoms) {
  let score = 0;
  
  // 症状权重计算
  symptoms.forEach(symptom => {
    if (symptom.severity === 'high') {
      score += 30;
    } else if (symptom.severity === 'medium') {
      score += 15;
    } else {
      score += 5;
    }
  });
  
  // 部位影响修正
  if (hasCriticalAreaSymptom(symptoms)) {
    score += 20;
  }
  
  return score;
}

### 2. 地图导航模块

#### 核心服务类
```javascript
// mapService.js
class MapService {
  // 搜索附近医院
  searchNearbyHospitals(latitude, longitude, radius) {
    return new Promise((resolve, reject) => {
      wx.request({
        url: 'https://apis.map.qq.com/ws/place/v1/search',
        data: {
          key: this.key,
          keyword: '24小时宠物医院',
          boundary: `nearby(${latitude},${longitude},${radius})`,
          page_size: 20
        },
        success: (res) => {
          resolve(this.formatHospitalData(res.data.data));
        }
      });
    });
  }
  
  // 计算距离
  calculateDistance(lat1, lon1, lat2, lon2) {
    const R = 6371000; // 地球半径
    const dLat = (lat2 - lat1) * Math.PI / 180;
    const dLon = (lon2 - lon1) * Math.PI / 180;
    const a = Math.sin(dLat/2) * Math.sin(dLat/2) +
              Math.cos(lat1 * Math.PI / 180) * Math.cos(lat2 * Math.PI / 180) *
              Math.sin(dLon/2) * Math.sin(dLon/2);
    const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
    return R * c;
  }
}
```

#### 位置权限管理
```javascript
// app.js 统一权限管理
requestLocationPermission() {
  return new Promise((resolve) => {
    if (this.globalData.locationPermission === 'granted') {
      resolve({ granted: true });
      return;
    }
    
    wx.getSetting({
      success: (settingRes) => {
        const hasPermission = settingRes.authSetting['scope.userLocation'];
        
        if (hasPermission) {
          this.globalData.locationPermission = 'granted';
          resolve({ granted: true });
        } else if (hasPermission === false) {
          this.globalData.locationPermission = 'denied';
          resolve({ granted: false });
        } else {
          wx.authorize({
            scope: 'scope.userLocation',
            success: () => {
              this.globalData.locationPermission = 'granted';
              resolve({ granted: true });
            }
          });
        }
      }
    });
  });
}
```

  ]
});

// symptom_records索引
db.collection('symptom_records').createIndex({
  indexes: [
    { field: 'openid', type: 'hashed' },
    { field: 'petId', type: 'standard' },
    { field: 'createdAt', type: 'standard' },
    { field: 'riskLevel', type: 'standard' }
  ]
});

## ⚠️ 版本局限与后续优化点

### 当前版本局限

#### 1. 功能局限
- **AI评估准确性**：基于规则的简单算法，需要机器学习模型优化
- **数据统计有限**：缺乏详细的用户行为分析和健康趋势统计
- **社交功能缺失**：无用户社区、经验分享等功能
- **提醒功能不足**：无疫苗、驱虫到期提醒功能

#### 2. 技术局限
- **地图API依赖**：完全依赖腾讯地图API，需要备用方案
- **离线模式缺失**：无法在无网络时查看历史记录
- **数据备份不足**：缺乏数据导出和备份功能
- **性能优化空间**：部分页面加载速度可进一步优化

#### 3. 业务局限
- **专业支持有限**：缺乏与宠物医生的直接对接
- **保险集成缺失**：未集成宠物保险服务
- **电商功能缺失**：无宠物用品购买功能
