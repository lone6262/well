## 项目概述

### 项目简介

宠物健康自查小程序是一款基于微信小程序的宠物健康管理工具，用户可以通过填写宠物症状进行健康风险评估，获取AI生成的专业健康报告，并支持会员订阅、邀请奖励等商业功能。

### 核心特性

- **症状自查评估**：基于规则引擎的智能风险等级评估（低/中/高）
- **AI健康报告**：DeepSeek AI 驱动的个性化健康报告生成
- **会员订阅系统**：月卡/年卡订阅，报告额度管理
- **邀请奖励机制**：用户邀请奖励和排行榜
- **附近医院导航**：基于腾讯地图API的24小时急诊医院搜索
- **宠物档案管理**：多宠物档案信息管理
- **知识库内容**：宠物健康知识文章

### 技术栈

- **前端**：微信小程序原生框架
- **后端**：微信云开发（云函数 + 云数据库）
- **AI服务**：DeepSeek Chat API
- **地图服务**：腾讯地图API
- **支付**：微信支付（支持模拟支付模式）

### 数据流向

1. **用户登录流程**
   ```
   小程序启动 → 静默登录获取openid → 游客模式 → 按需授权 → Token生成
   ```

2. **症状自查流程**
   ```
   选择宠物 → 选择症状 → 提交 → 规则引擎评估 → 保存记录 → 显示结果
   ```

3. **AI报告生成流程**
   ```
   创建订单 → 扣减额度 → 查询缓存 → AI生成(或模板回退) → 写入缓存 → 返回报告
   ```

## 开发规范

### 命名规范

1. **文件命名**
   - 云函数：camelCase (submitSymptom)
   - 页面：kebab-case (symptom-guide)
   - 组件：kebab-case (cloud-tip-modal)

2. **变量命名**
   - 常量：UPPER_SNAKE_CASE (USER_STATUS)
   - 变量/函数：camelCase (getUserInfo)
   - 数据库字段：snake_case (user_id)

3. **集合命名**
   - 数据库集合：snake_case (symptom_records)
   - 复数形式 (users, pets, orders)

### 代码规范

1. **注释规范**
   ```javascript
   /**
    * 函数功能说明
    * @param {类型} 参数名 - 参数说明
    * @returns {类型} 返回值说明
    */
   function example(param) {
     // 实现代码
   }
   ```

2. **错误处理**
   ```javascript
   try {
     // 业务逻辑
   } catch (error) {
     console.error('[云函数名] 错误描述:', error.message);
     return {
       code: RESPONSE_CODE.SERVER_ERROR,
       msg: '用户友好的错误信息',
       data: {}
     };
   }
   ```

3. **日志规范**
   ```javascript
   logger.info('操作描述', additionalData);
   logger.warn('警告信息', warningData);
   logger.error('错误信息', errorDetails);
   ```

### Git 提交规范

```
<type>(<scope>): <subject>

类型:
- feat: 新功能
- fix: Bug修复
- docs: 文档更新
- style: 代码格式
- refactor: 重构
- chore: 构建/工具

示例:
feat(member): 添加会员订阅功能
fix(symptom): 修复症状评估边界条件
docs: 更新部署文档
```
