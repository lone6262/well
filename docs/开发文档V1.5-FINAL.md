## 1. 项目概述

### 1.1 项目简介

Mewora 宠物AI助手是一款基于微信小程序的宠物健康管理平台。用户通过填写宠物症状进行健康风险评估，获取 DeepSeek AI 生成的专业健康报告，支持会员订阅、邀请裂变等商业化功能，并配备 Web 管理后台。

### 1.2 基本信息

| 项目 | 值 |
|------|-----|
| 项目名称 | Mewora / pet-symptom-check |
| AppID | `wxee33a0c47421db2c` |
| 云开发环境 ID | `cloud1-d8gdi44zqfec250b5` |
| 静态托管域名 | `well-tools-d8gwhxdlcf84937ed-1435021389.tcloudbaseapp.com` |
| 管理后台路径 | `/cloud-admin/index.html` |
| 当前版本 | V1.5 商业化增强版 |

### 1.3 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 小程序前端 | 微信小程序原生框架 | WXML + WXSS + JavaScript |
| 后端服务 | 微信云开发 CloudBase | 云函数 + 云数据库 + 云存储 |
| AI 引擎 | DeepSeek Chat API | 报告生成 + 模板回退 |
| 地图服务 | 腾讯地图 API | 附近医院搜索 |
| 支付系统 | 微信支付 | 支持模拟/真实支付切换 |
| 管理后台 | HTML5 + Vanilla JS | CloudBase 静态网站托管 |
| 后台认证 | JWT (HMAC-SHA256) | 独立管理员 Token |
| Web SDK | `@cloudbase/js-sdk` v2 | 本地部署，匿名登录 |

## 6. 云函数详解

### 6.1 云函数清单

> 撰写本文档时共 49 个云函数，现已增至 77 个（含 quickstartFunctions 示例）。下表为 V1.5 核心函数，新增函数见 `cloudfunctions/` 目录。

#### 用户认证（3个）

| 云函数 | 文件 | 功能 | 调用方 |

#### 症状评估（4个）

| 云函数 | 功能 |

## 7. 管理后台系统

### 7.1 概述

管理后台是一个纯静态 HTML5 Web 应用，部署在 CloudBase 静态网站托管上。通过 CloudBase Web SDK 匿名登录获取访问凭证，调用 admin 系列云函数完成后台管理操作。

### 7.2 技术特点

| 特性 | 实现 |
|------|------|
| 框架 | 零依赖 Vanilla JavaScript |
| 认证 | 双层：CloudBase 匿名登录 + JWT adminToken |
| SDK | `@cloudbase/js-sdk` v2 本地部署（lib/cloudbase.js） |
| 存储 | localStorage 保存 adminToken（24h 过期） |
| UI | 原生 CSS Grid + Flexbox 响应式布局 |
| 浏览器 | Chrome 80+, Edge 80+, Firefox 75+, Safari 13+ |

### 7.3 部署要点

| 配置项 | 位置 | 说明 |
|--------|------|------|
| 环境 ID | `js/config.js` → `TCB_CONFIG.env` | CloudBase 环境 ID |
| SDK 文件 | `lib/cloudbase.js` | ~540KB，本地部署，无需 CDN |
| 匿名登录 | CloudBase 控制台 → 登录授权 → 开启 | SDK 认证必需 |
| 云函数权限 | 每个 admin* 函数 → 所有用户可调用 | 匿名用户调用必需 |
| 数据库权限 | `system_config` → 所有用户可读 | `warmupConfig` 读取必需 |

## 8. 核心业务流程

### 8.1 用户登录流程

```
小程序启动 → 静默登录(openid) → 游客模式
    │
    ├─ 按需授权 → wx.getUserProfile → quickLogin → 保存用户信息 → Token
    │
    └─ 本地存储 Token → 下次启动自动恢复
```

### 8.2 症状自查 → AI 报告流程

```
选择宠物 → 选择症状(多选) → submitSymptom
    │
    ├─ 规则引擎判定风险等级（低/中/高）
    ├─ 中高风险：警告提示 + 建议就医
    └─ 保存评估记录
         │
         └─ 获取 AI 报告:
              createOrder → 解析额度(首份/会员/邀请/付费)
                  │
                  ├─ 免费额度: 扣减 → generateAIReport
                  └─ 额度不足: 微信支付 → payCallback → generateAIReport
                       │
                       └─ AI 生成:
                            ├─ 缓存命中 → 返回
                            ├─ DeepSeek API 成功 → 写缓存 → 返回
                            └─ API 失败 → 模板回退 → 返回
```

### 8.3 会员订阅流程

```
选择月卡/年卡 → createOrder(type=member) → 微信支付
    │
    └─ payCallback:
         ├─ 更新 orders 状态为 paid
         ├─ memberActivate:
         │    ├─ 创建/更新 members 记录
         │    ├─ 设置有效期 (30/365天)
         │    ├─ 初始化报告额度 (5/15次)
         │    └─ 更新 users.isMember = true
         └─ 通知用户
```

### 8.4 邀请裂变流程

```
用户A → createInvite → 获取邀请码
    │
    └─ 用户B 通过邀请码注册:
         ├─ processInviteReward:
         │    ├─ 写入 invite_records
         │    ├─ 给用户A 增加邀请奖励额度
         │    └─ 更新排行榜
         └─ 用户A 可用奖励额度生成报告
```

## 11. 已知局限与改进方向

### 11.1 当前局限

| 局限 | 详情 | 影响 |
|------|------|------|
| 模拟支付 | 当前 MOCK_PAY=true，无需真实支付即可完成订单 | 仅开发/测试环境可用 |
| AI 依赖 | DeepSeek API 不可用时回退到模板报告 | 模板内容有限 |
| 地图数据 | 24h 医院基于关键词匹配，非实时数据 | 可能信息不准确 |
| 邀请防作弊 | 仅基础检测，无复杂防刷机制 | 建议监控异常 |
| 云函数冷启动 | 首次调用有 1-3s 延迟 | 影响用户体验 |
| 管理后台 SDK | Web SDK v2 的 `callFunction` 有 `scope` bug，需显式匿名登录 | 已修复，但增加初始化复杂度 |

### 11.2 改进方向

| 优先级 | 项目 | 说明 |
|--------|------|------|
| 🔴 高 | 真实微信支付接入 | 替换 MOCK_PAY，接入真实支付 + 签名验证 |
| 🔴 高 | AI 报告质量提升 | 扩充模板、优化 Prompt、增加多模型支持 |
| 🟡 中 | 管理后台功能增强 | 操作日志、数据导出、批量操作 |
| 🟡 中 | 性能优化 | CDN 加速、数据库查询优化、缓存策略 |
| 🟢 低 | 安全加固 | 邀请防作弊、敏感操作审计、异常登录检测 |
| 🟢 低 | 多端扩展 | 支持 H5 公众号版本、App 端 |

## 12. 开发规范

### 12.1 命名规范

| 分类 | 规范 | 示例 |
|------|------|------|
| 云函数 | camelCase | `submitSymptom`, `generateAIReport` |
| 小程序页面 | kebab-case | `symptom-guide`, `ai-report` |
| 组件 | kebab-case | `cloud-tip-modal` |
| 常量 | UPPER_SNAKE_CASE | `MEMBER_DURATION`, `ORDER_TYPES` |
| 变量/函数 | camelCase | `getUserInfo`, `checkReportQuota` |
| 数据库字段 | snake_case | `user_id`, `out_trade_no` |
| 数据库集合 | snake_case 复数 | `symptom_records`, `knowledge_articles` |

### 12.2 代码规范

- **文件大小**：200-400 行典型，800 行上限
- **函数大小**：< 50 行
- **嵌套深度**：< 4 层
- **不可变性**：创建新对象，不修改现有对象
- **错误处理**：每个 try-catch 提供用户友好的错误消息
- **日志**：使用 `logger.js` 统一日志格式（禁止 `console.log`）
- **魔法数字**：全部提取为命名常量

### 12.3 Git 提交规范

```
<type>(<scope>): <subject>

类型: feat / fix / docs / style / refactor / test / chore / perf

示例:
feat(member): 添加会员订阅功能
fix(symptom): 修复症状评估边界条件
docs: 更新 V1.5 开发文档
```

### 13.1 监控指标

| 指标 | 查看位置 |
|------|----------|
| 云函数调用量/错误率 | 云开发控制台 → 云函数 → 监控 |
| 数据库读写量 | 云开发控制台 → 数据库 → 监控 |
| 存储使用量 | 云开发控制台 → 存储 |
| 静态网站访问量 | 云开发控制台 → 静态网站托管 |

### 13.2 日常维护

| 频率 | 操作 |
|------|------|
| 每日 | 检查管理后台 → 数据统计面板 |
| 每周 | 检查云函数错误日志、限流日志 |
| 每月 | 备份数据库、清理过期数据、检查配额使用情况 |
| 按需 | 通过管理后台调整价格/额度配置（实时生效） |

### 13.3 故障排查

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 云函数超时 | DeepSeek API 响应慢 | 检查 API Key 有效性、网络状态 |
| 报告生成失败 | API 额度耗尽 | 切换模板回退模式 |
| 管理后台无法登录 | 匿名登录未开启 | CloudBase 控制台检查登录授权 |
| 管理后台加载失败 | 云函数权限未放开 | 确认 admin* 函数权限为所有用户可调用 |
| 数据库写入失败 | 配额超限 | 升级套餐或清理数据 |

### 13.4 密钥轮换

如需更换密钥：

1. CloudBase 控制台 → 数据库 → `system_config` 集合
2. 修改对应的 `key` 记录（如 `admin_secret`、`token_secret`）
3. 管理后台会通过 `warmupConfig` 自动加载新密钥
4. 已签发的旧 Token 会在 24h 内自动过期
