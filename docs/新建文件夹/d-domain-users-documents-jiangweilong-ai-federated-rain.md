### 四、价格优先级 & 计算规则

#### 4.1 额度扣减优先级

```
① 邀请奖励免费次数  →  免费使用
② 体验会员额度       →  免费使用（限 1 次/月）
③ 正式会员额度       →  免费使用（个人 3 次 / 家庭 6 次）
④ 点数包余额         →  消耗 1 个点数
⑤ 优惠券 + 按次付费  →  计算优惠后金额，微信支付
```

#### 4.2 优惠券计算流程

```
原始金额 → 检查可用券 → 自动选中最大优惠券 → 计算优惠后金额
  ↓
折扣价 = max(原始金额 - 优惠券面值, 0)   // fixed 类型
折扣价 = 原始金额 × 折扣百分比           // percent 类型
  ↓
最终实付 = max(折扣价, 0)               // 最低为 0（免费）
```

#### 4.3 金额约束

- **禁止前端计算金额** — 所有价格计算在后端 `createOrder` 中完成
- **优惠券不可叠加** — 每笔订单最多使用 1 张券
- **套餐不可使用优惠券** — 套餐已含折扣，不叠加券
- **续费价与首充价分开** — 由 `is_first_purchase` 标志判断
- **召回专享价通过专属优惠券实现** — 不单独建 SKU，发一张大额券即可
